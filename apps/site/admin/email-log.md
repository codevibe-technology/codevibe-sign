# Email log

When someone says they never got a signing email, **Settings, Email log** shows what was
sent. Owners and admins can open it.

Each row shows the kind of email, the recipient, the subject, whether it was **Sent** or
**Failed** with the error, any attachments and the Message-ID. Enter an **Envelope id** to see
only one envelope's emails; the envelope page has the same list under
**Emails for this envelope**.

The log keeps 90 days and shows the latest 200 rows. It never keeps the text of a message or
its links, so a signing link cannot be taken from it.

**Sent** means the mail server accepted the email. If the person still has nothing, ask them
to look in spam, then send it again with **Resend link** on the envelope, or give them a link
yourself; see [Fix an envelope after sending](/guides/fix-after-sending).
